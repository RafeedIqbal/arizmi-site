# Arizmi brand source archive

This directory preserves the supplied Arizmi Labs brand package byte-for-byte. It is intentionally outside `public/` so editable artwork, print files, font sources, licences, and unused variants are not deployed as public website assets.

Production-ready derivatives live in `public/assets/arizmi/` and `public/fonts/`. Add or update a runtime derivative there only when the site uses it, then document the mapping in [`../runtime-assets.md`](../runtime-assets.md).
